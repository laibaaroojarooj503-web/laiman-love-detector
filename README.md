## Overview
The Lie Detector Game is an interactive and fun application where players ask each other questions and guess whether the answers are true or false.  
It is designed for entertainment, testing observation skills, and increasing interaction among friends.

## Features
- Ask and answer questions with friends.
- Detect whether the responses are true or false.
- Fun and engaging for parties or casual gatherings.
- Improves observation and judgment skills.

## Technology Used
*(Adjust according to your implementation)*
- **Frontend:** HTML, CSS, JavaScript
- **Optional:** Backend support using PHP or Node.js
- **Logic:** Truth/Lie detection algorithm (simple or advanced)

## How It Works
1. Players take turns asking questions.
2. The responder answers with truth or a lie.
3. The system (or other players) guesses if the answer is true or false.
4. Scores are tracked to determine who is best at detecting lies.

## Benefits
- Fun and interactive game for friends.
- Encourages social interaction and engagement.
- Enhances observation and critical thinking skills.

## Future Improvements
- Add an AI module for automatic lie detection.
- Include a scoring system with leaderboards.
- Add a timer for responses to make it more challenging.
